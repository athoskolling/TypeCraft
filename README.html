Architecture

3-Layer Diagnostic Engine

Every submission flows through a real TypeScript compiler, an isolated CommonJS runtime worker, and a heuristic logic analyzer before delivering actionable feedback.

LAYER 01

Strict Compiler & AST

src/engine/layer1Compiler.ts
  • Runs ts.createProgram in strict: true against bundled ES2023 definitions.
  • Evaluates compile-time assertions (Expect, Equal, IsAny, Alike).
  • Translates cryptic diagnostics (TS2322, TS2339, TS2345, TS7006, TS2532) into clear explanations.
  • Enforces AST rules: blocks explicit any / @ts-ignore and verifies required generics, narrowing, predicates, classes, or async usage.
LAYER 02

Sandbox Web Worker

src/engine/layer2Runner.ts
  • Executes inside a dedicated Web Worker with a 4.5s watchdog that terminates and respawns hung loops.
  • Bundles 4-file Mini-Projects via an in-memory CommonJS resolver with cross-file IntelliSense.
  • Supports beecrowd I/O, leetcode DSA, type-challenge, and async Promise harnesses.
  • Captures console.log output and verifies checkImmutability on input arrays/objects.
LAYER 03

Smart Logic Analyzer

src/engine/layer3LogicAnalyzer.ts
  • Detects forgotten return statements when a function yields undefined.
  • Identifies in-place input array or object mutations automatically.
  • Flags off-by-one (±1) counts, boundary slices, and wrong element ordering.
  • Catches .toFixed() decimal rounding drift and Beecrowd trailing whitespace/newline mismatches.

Skip-Ahead & Early Access Gates

  • Jump Here (Cumulative Exam): Available on every locked section. Hints are disabled during exams to ensure genuine mastery.
  • Tested Out Status: Passing a higher section's Cumulative Exam immediately unlocks that section and marks all prior sections as Tested Out (still playable anytime).
  • Try Mini-Project Early: Inspect and build any section's 4-file architecture workspace before unlocking its phase track.
  • Bottom Dock: Switch seamlessly between Test Results & Diagnostics, Console, and Custom Input / Playground.
